# Execução do frontend

O frontend agora usa Vite. Consulte [README.md](README.md) para comandos,
mapa dos módulos, testes e publicação da pasta `dist/`.

```sh
cd frontend
npm ci
npm run dev
```

O endereço local aparece no terminal. O backend continua sendo executado
separadamente conforme suas instruções. Não abra `index.html` diretamente.
